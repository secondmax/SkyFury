**SkyFury** (formerly *Neon Strike*) is a high-octane, neon-drenched arcade flight shooter built for the modern web. Pilot advanced fighters through a relentless barrage of enemies, upgrade your weapons, and take down massive mechanical fortresses.

---

## 🚀 Features

-   **Stunning Neon Aesthetics**: A sleek, dark-mode interface with vibrant glow effects and glassmorphism UI.
-   **Dynamic Parallax Background**: Deep space environment with multi-layered star fields.
-   **Ship Customization**: Choose from three distinct flight profiles:
    -   ⚡ **Speedster (闪电侠)**: Unmatched agility and a tight profile.
    -   ⚖️ **Balanced (平衡者)**: All-around performance for any situation.
    -   🛡️ **Juggernaut (重装兵)**: High presence and steady handling.
-   **Advanced Weaponry**:
    -   🔴 **Laser (L)**: A continuous high-energy beam that shreds through everything.
    -   🟡 **Shotgun (S)**: Devastating close-range spread fire.
    -   🟢 **Three-Way (3)**: Wide-angle coverage for crowd control.
    -   🔥 **Auto-Evolution**: Your base weapon upgrades automatically as you reach higher scores.
-   **Diverse Enemy Roster**:
    -   **Scouts**: Fast and evasive.
    -   **Fighters**: Standard tactical units.
    -   **Tanks**: Heavy armored units with explosive munitions.
    -   **Bosses**: Elite ships with complex bullet patterns.
    -   **The Fortress**: A screen-filling behemoth that challenges your survival skills.

---

## 🎮 How to Play

1.  **Select Your Ship**: Pick the fighter that suits your playstyle from the start screen.
2.  **Move**: Drag your **Mouse** or use **Touch** to navigate. Your ship fires automatically.
3.  **Collect Power-ups**: Destroy enemies to drop weapon upgrades.
4.  **Survive**: Avoid enemy bullets and collisions. Watch out for explosive rounds!

---

## 🛠️ Technical Overview

-   **Engine**: Pure HTML5 Canvas API.
-   **Styling**: Modern CSS3 with `backdrop-filter` and custom animations.
-   **Input**: Universal event listeners for seamless Mouse and Touch interaction.
-   **Performance**: Optimized particle system and collision detection for smooth 60FPS gameplay.

## 📦 Installation & Development

To run SkyFury locally:

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/SkyFury.git
    ```
2.  Open `index.html` in any modern web browser.
3.  (Optional) For the best experience with assets, use a local server:
    ```bash
    npx serve .
    ```
